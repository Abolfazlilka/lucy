# Lucy Documentation

Lucy documentation is split by purpose so beginners and experienced programmers can both find the right level of detail.

## Start here

- `TUTORIAL.md` — learn Lucy step by step from the beginning.
- `REFERENCE.md` — complete language reference, built-ins, globals, syntax, semantics, and CLI behavior.
- `STDLIB.md` — complete standard-library API reference.

## For daily use

- `CLI.md` — running programs, REPL, options, and `ARGV`.
- `ERRORS.md` — error categories and debugging guidance.

## For contributors

- `ARCHITECTURE.md` — interpreter and runtime architecture.
- `ROADMAP.md` — planned development direction.
- `HISTORY.md` — preserved release history and additions.

## Documentation principle

Examples are intentionally short enough to understand, but the reference documents exact signatures, return values, type rules, limitations, and platform dependencies.

- [REPL](REPL.md) — Interactive editing, history, and completion.
